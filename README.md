# Site Statique - Exercice React

## 📋 Description

Projet d'exercice pour reproduire un site vitrine en utilisant React et Vite. L'objectif est de maîtriser les fondamentaux du HTML, CSS et JavaScript dans un environnement moderne tout en appliquant les méthodes agiles pour améliorer la productivité et suivre l'avancement du projet.

## 🚀 Technologies utilisées

- **React** - Bibliothèque JavaScript pour construire l'interface utilisateur
- **Vite** - Outil de build rapide et serveur de développement
- **HTML5** - Structure sémantique
- **CSS3** - Stylisation et mise en page
- **JavaScript ES6+** - Logique et interactivité

## 📦 Installation

1. Clonez le repository :
```bash
git clone https://github.com/michel97400/-exo_site_statique.git
cd -exo_site_statique
```

2. Installez les dépendances :
```bash
npm install
```

## 🔧 Scripts disponibles

- `npm run dev` - Lance le serveur de développement
- `npm run build` - Compile le projet pour la production
- `npm run preview` - Prévisualise la version de production
- `npm run lint` - Vérifie la qualité du code

## 🏃‍♂️ Lancement du projet

Pour démarrer le serveur de développement :

```bash
npm run dev
```

Le site sera accessible à l'adresse : `http://localhost:5173`

## 🎯 Objectifs pédagogiques

- ✅ Maîtriser les fondamentaux du HTML sémantique

- ✅ Utiliser JavaScript moderne (ES6+, modules, async/await)
- ✅ Comprendre l'architecture des composants React
- ✅ Implémenter des méthodes agiles pour le suivi du projet
